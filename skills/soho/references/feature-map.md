# Feature map per transport

This page lists every command the soho CLI dispatches and what each does on the two worker transports: the legacy Herdr TUI (`transport=herdr`, the default) and native Herdr Core (`transport=hc`).

It describes the committed Go code, not the plan. Where the code does not settle a behavior, the cell says `unknown`. Each table row ends with an HTML comment that cites `file:line` for every claim in the row.

The transport is the configuration key `transport`; the environment variable `SOHO_TRANSPORT` wins over the files, and any value other than `hc` counts as `herdr` (`internal/core/config.go:384-395` `TransportMode`). `cli.Run` writes the resolved value back to `SOHO_TRANSPORT` before any backend is built (`internal/cli/cli.go:551-561` `transportModeFor`).

## Glossary

| Noun | Definition |
|---|---|
| orchestrator | The calling agent. It spawns one CLI agent per role, dispatches briefs, collects reports and owns integration, gates and git (`skills/soho/SKILL.md:3-8`). |
| worker | A CLI agent that `soho spawn` starts for one role, recorded as one row of the roster (`internal/core/state.go:19` `rosterHeader`). |
| role | A markdown file with frontmatter (`roles/<role>.md`, overridable per project in `.agents/soho-roles/<role>.md`) that gives a worker its instructions (`internal/cli/usage.go:3` `usage`). |
| lane | A named capacity group that workers are named after (`build`, `review`, `docs`); `lanes=on` is the default (`skills/soho/config.defaults:108`, `skills/soho/SKILL.md:102`). |
| kind | The CLI agent a worker runs: `claude`, `codex`, `grok`, `agy`, `gemini`, `cursor`, `pi`, `opencode` (`internal/kinds/kinds.go:11` `KnownKinds`). |
| brief | The markdown file the orchestrator writes and `soho dispatch <agent> <brief.md>` composes with the role body into the prompt (`skills/soho/templates/brief.md`, `internal/cli/usage.go:3` `usage`). |
| report | The file a worker writes when it finishes. Without an assignment, a worker is done when its report exists (`internal/cli/usage.go:3` `usage`, "Completion contract"). |
| roster | `agents.tsv` in the state directory: one tab-separated row per worker with name, pane, kind, role, family, created_pane, cwd, started, model, approvals, roles and lane (`internal/core/state.go:19` `rosterHeader`). |
| state directory | `<state root>/<workspace id>`; the state root defaults to `.soho` (`skills/soho/config.defaults:299`). It holds `briefs/`, `reports/`, `wait/` and the roster (`internal/core/state.go:224-231` `StateDir`). |
| terminal | The unit of `hc`: a persistent program with an address such as `t7` (`skills/soho/references/herdr-ui.md:13`). In the transport contracts it is "one registered agent" (`internal/transport/contracts.go:148` `Terminal`). |
| pane / panel | A split of a Herdr TUI tab that hosts one agent; its id comes from `HERDR_PANE_ID` (`internal/herdr/backend.go:188-195` `Caller`). The skill says "panel" when it talks to the user about a pane (`skills/soho/SKILL.md:71-76`). On hc the pane id field carries the terminal address (`internal/hcbackend/backend.go:608-611` `Caller`). |
| tab | A Herdr TUI tab holding panes. A herd tab is the overflow tab labelled by `herd_label` (`skills/soho/config.defaults:74-84`). The hc backend has no tabs (`internal/hcbackend/backend.go:1082-1084` `ListTabs`). |
| space | The top-level grouping of native `herdr-app`: `spaces[].tabs[].terminals[]` (`skills/soho/references/herdr-ui.md:25`). The soho transport contracts have no space operation (`internal/transport/contracts.go:413-443` `Transport`, `internal/transport/contracts.go:449-479` `Window`). |
| parent | On hc, the terminal that spawned a worker, sent as `caller` and required to be non-empty (`internal/hc/terminal_run.go:319` `Client.RunTerminal`, `internal/hc/terminal_run.go:402` `validateTerminalRun`). The herdr start request has no parent field (`internal/transport/contracts.go:252-286` `Start`). |
| session | The id that names the state directory. On hc it is the `soho.session` label of the caller's terminal, or `hc-<address>` without the label (`internal/hcbackend/backend.go:99-102` `Session`). On herdr it is `HERDR_WORKSPACE_ID` (`internal/herdr/backend.go:188-195` `Caller`). |
| transport | The backend that runs workers: `herdr` (`internal/herdr`) or `hc` (`internal/hcbackend`), chosen by `internal/backend/backend.go:23-28` `New`. |

## Command table

The table has one row per entry of `knownCommands` (50 commands, `internal/cli/cli.go:35-46` `knownCommands`). Status on `hc` is one of `same` (the command path has no transport branch and no backend difference that changes what the user sees), `differs` (a transport branch or a backend method that is a no-op or unsupported on hc changes the result; the hc cell says how), `refused` (the entry guard stops the command; the hc cell quotes the message) or `no-op` (no row has this status; the no-op calls are listed under "Known gaps on the native transport").

Refused commands print `soho: <command> does not support transport=hc yet; set transport=herdr or see DJA-604` on stderr and exit 2. The guard text is `internal/cli/cli.go:263` `Run`. The exact `<command> --help` or `-h` (one flag after a known command, outside `SOHO_NOWRITE`) prints that command's lines before the guard, refused commands included (`internal/cli/cli.go:132-137` `Run`); any longer form of a refused command is refused at the guard.
